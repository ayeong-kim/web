# 동물병원 웹서버

브라우저 화면(HTML/JS)을 제공하고, `/api/*` 요청을 WAS로 전달하는 웹서버입니다.
Python 표준 라이브러리만 사용하므로 따로 설치할 패키지가 없습니다.

```
브라우저 ── /            → static/index.html, app.js
        └─ /api/desk/... → WAS /desk/... (본문·쿠키 그대로 전달)
```

## 실행

WAS를 먼저 실행한 뒤 웹서버를 실행합니다.

```bash
python server.py
```

- 주소: `http://127.0.0.1:8080`
- 화면 파일(`static/`)을 고친 경우 서버 재시작 없이 새로고침하면 반영됩니다.

## 설정 (환경변수)

로컬에서는 `.env.example`을 `.env`로 복사해서 고치면 되고, 클라우드에서는 환경변수로 직접 넣으면 됩니다(같은 값이 둘 다 있으면 환경변수가 우선). 아무것도 없으면 아래 기본값으로 실행합니다.

| 이름 | 기본값 | 설명 |
|---|---|---|
| `WEB_HOST` | `127.0.0.1` | 웹서버 주소. 클라우드(컨테이너/VM)는 `0.0.0.0` |
| `WEB_PORT` | `8080` | 웹서버 포트 |
| `WAS_URL` | `http://127.0.0.1:8000` | `/api/*` 요청을 보낼 WAS 주소. 클라우드는 WAS의 내부 주소나 서비스 이름 |
| `WAS_TIMEOUT` | `30` | WAS 응답 대기 시간(초) |

- 브라우저는 웹서버에만 접속하고, WAS는 웹서버를 통해서만 호출됩니다. 클라우드에서는 WAS를 외부에 공개하지 않아도 됩니다.
- HTTPS로 서비스하면 WAS의 `COOKIE_SECURE=true`도 같이 설정하세요.

## 테스트 계정

비밀번호는 WAS의 `SEED_PASSWORD` 값입니다(저장소에는 적지 않습니다). 로그인하면 계정 권한에 따라 데스크 / 수의사 화면으로 이동합니다.

| 지점 | 데스크 (간호사) | 수의사 |
|---|---|---|
| 강남점 | `desk1` 김간호 | `vet1` 이수의, `vet2` 박수의 |
| 홍대점 | `desk2` 최간호 | `vet3` 정수의, `vet4` 한수의 |
| 서초점 | `desk3` 윤간호 | `vet5` 강수의, `vet6` 조수의 |
| 잠실점 | `desk4` 임간호 | `vet7` 신수의, `vet8` 오수의 |
| 분당점 | `desk5` 서간호 | `vet9` 권수의, `vet10` 황수의 |

- 보호자와 반려동물은 지점별로 나뉩니다. 다른 지점에서 등록한 보호자는 검색되지 않습니다.
- 방문 등록 때 담당 수의사는 같은 지점 수의사 중에서만 고를 수 있습니다.
- 같은 브라우저의 여러 탭은 로그인 쿠키를 공유합니다. 데스크와 수의사 계정을 동시에 쓰려면 다른 브라우저나 시크릿 창을 사용하세요.

## 화면

| 권한 | 화면 |
|---|---|
| 데스크 | 진료 접수(보호자 검색), 신규 보호자 등록, 보호자 상세, 반려동물 상세(기본 정보 / 진료 이력), 방문 등록 |
| 수의사 | 진료 목록, 현재 진료(진단 작성, 진료 종료) |

- 진료 목록, 보호자 상세, 반려동물 상세는 5초마다 자동으로 다시 조회합니다(수정 중일 때는 건너뜀).
- 대기·진료중인 방문이 있는 반려동물은 진료가 끝날 때까지 방문 등록 버튼이 비활성화됩니다.
